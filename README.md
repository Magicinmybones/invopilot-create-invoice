# invopilot-create-invoice

Standalone static prototype from `invopilot-create-invoice(1).html`.

The deployable site is in `site/`. Embedded images and fonts were extracted to `site/assets/`.

## Deploy

```sh
npx wrangler pages deploy site --project-name invopilot-create-invoice --branch main
```
